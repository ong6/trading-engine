# Weekly operator digest

`farm.p16_operator_digest` generates `<YYYY-MM-DD>.md` here after the Sunday walk-forward drain.
Each compact report summarizes the existing P15 and P16 gates, paper books, challenger deflation,
filing/event activity, fill observations, producer health, and owner inputs. It is a read-only
operational view and grants no promotion, broker, execution, or real-capital authority.

The model identity warning is deliberately repeated in every generated digest: the current model
version is an unversioned catalogue alias and is not an immutable identity for real capital.
